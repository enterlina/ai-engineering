# AI Engineering Portfolio

A collection of practical AI Engineering projects covering retrieval-augmented
generation, LLM evaluation, information retrieval, agents, model integration,
and production-oriented experimentation.

## Projects

| Project | Description | Key results |
|---|---|---|
| [FilmScope RAG Assistant](projects/filmoskop-rag) | Russian-language support RAG system with corpus cleaning, routed BM25+dense retrieval, cross-encoder reranking, grounded generation, and evaluation | Recall@5: **0.9464**, MRR: **0.8296** |

## Repository structure

```text
ai-engineering/
├── projects/
│   └── filmoskop-rag/
└── README.md
```

Each project has its own README, reproducible notebooks, dependency list, and
documented evaluation results. Credentials, downloaded datasets, model weights,
and large runtime checkpoints are excluded from version control.
